# ChatGPT 프로젝트 '가민' 수동 업로드 가이드

## 1) Obsidian에서 리포트 파일 찾기
- 저장 경로: `Garmin/Weekly Reports`
- 파일명: `YYYY-MM-DD_Garmin_Weekly_Report.md`
- 함께 업로드할 원본 JSON: `data/raw/*.json`, `data/processed/*.json`

## 2) ChatGPT 프로젝트 '가민'에 업로드
1. ChatGPT에서 프로젝트 `가민` 열기
2. 프로젝트의 Sources(소스) 영역으로 이동
3. `Add files` 또는 업로드 버튼 클릭
4. 해당 주차 Markdown 리포트와 JSON 파일을 선택하여 업로드

## 3) 주간 리포트를 프로젝트 Sources에 추가하는 팁
- 파일명에 날짜를 포함해 정렬이 잘 되도록 유지
- 한 주 단위로 Markdown 1개 + 원본/가공 JSON 2개를 함께 업로드
- 누적 분석을 위해 최근 4주 이상 자료를 유지

## 4) 프로젝트 '가민' 추천 질문 예시
1. 이번 주 HRV 하락 원인을 수면과 운동량 관점에서 분석해줘.
2. 이번 주 러닝 부하는 다음 주 장거리주를 해도 될 정도인지 판단해줘.
3. 최근 4주 리포트를 비교해서 과훈련 가능성을 분석해줘.
4. 내 마라톤 예상 기록 변화와 VO2max 변화를 연결해서 설명해줘.
5. 다음 주 훈련 계획을 회복 중심, 유지 중심, 기록 향상 중심으로 나눠서 제안해줘.
