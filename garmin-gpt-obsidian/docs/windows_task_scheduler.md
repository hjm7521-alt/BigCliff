# Windows 작업 스케줄러 등록 가이드

## 1) 사전 준비
- Python 3.11+ 설치
- 프로젝트 경로 확인 (예: `C:\Users\you\garmin-gpt-obsidian`)
- `.env` 작성

## 2) 작업 만들기
1. 작업 스케줄러 실행
2. [작업 만들기] 클릭
3. 이름: `Garmin Weekly Report`
4. [트리거] 탭 -> [새로 만들기]
   - 매주
   - 일요일
   - 시간: `20:00:00`
5. [동작] 탭 -> [새로 만들기]
   - 프로그램/스크립트: `python`
   - 인수 추가: `src/main.py`
   - 시작 위치: 프로젝트 루트 경로
6. [조건], [설정]은 PC 환경에 맞게 조정

## 2-1) '일요일 20:00에 PC가 꺼져 있었던 경우' 자동 보완 설정(중요)
작업 속성 -> [설정] 탭에서 아래 옵션을 반드시 체크하세요.

- `예약된 시작을 놓친 후 가능한 빨리 작업 실행`

이 옵션을 켜면, 예를 들어 일요일 20:00에 PC가 꺼져 있고 월요일 10:00에 PC를 켠 경우,
작업 스케줄러가 놓친 작업을 가능한 빨리 실행합니다.

프로그램 자체도 주간 기준일을 '가장 최근 일요일'로 계산하므로,
월요일 실행 시에도 전날(일요일) 기준 주간 리포트가 생성됩니다.

## 3) 시간대 주의
- Windows 시스템 시간대를 `한국 표준시(UTC+09:00)`로 맞춰야 Asia/Seoul 기준과 일치합니다.
